# Corrai Admin Client

Vue 3 + TypeScript admin frontend for listing schools and monitoring Redis queues.

## Quick Start

```bash
cd admin_client
npm install
npm run dev
```

The development server runs with base path `/corrai_test_adm/`.

## Build

```bash
npm run build
```

Output is written to `dist/` and served at `/corrai_test_adm/` by nginx.
